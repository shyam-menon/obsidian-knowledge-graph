# 03 — Dashboard

The MPC Dashboard is the landing page after login. It displays configurable widgets giving partners at-a-glance access to their pipeline.

## Key Behaviours

### Available Widgets
| Widget | Description |
|--------|-------------|
| Customer Lookup | Enter customer name → quick links into that customer's record |
| Recent Opportunities | Last-updated opportunities |
| Active Proposals | Graph of proposals by status (In Progress, Approved, Alternate, Rejected) |
| Recent Proposals | Last-updated proposals |
| Approved Proposals | Last proposals in HP Approved status |
| Alternate Proposals | Last proposals in HP Alternate status |
| In Progress Proposals | Last proposals in In Progress status |
| Active Proposals (diagram) | Visual chart of proposals across statuses |

### Customisation
- Click the **Customise** button (top right) to enter edit mode
- **Add a widget**: drag from the library on the left onto an empty box or replace an existing widget
- **Remove a widget**: click the X in its corner
- Click **Save Changes** to persist the layout
- Widget configuration is **per-user** (not shared across the team)
