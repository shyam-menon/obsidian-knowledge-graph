# 09 — Software Management

Software solutions can be added to a proposal alongside hardware, or offered as a standalone option for Add-on deals. They are managed through the Proposed Software section of the proposal.

## Key Behaviours

### Adding Software
- Navigate to the **Proposed Software** section within the proposal
- **Software Global Search tab**: search for a solution by Software Description
- For each solution, specify: type, quantity, pre-defined description, location, customer solution administrator
- Selected solutions appear in a **cart** (basket) on the right of the screen
- To remove: click the Bin icon or use the Delete Selected button

### Summary
- A summary at the top of the Proposed Software section shows the total count of software solutions in the cart

### Standalone Add-on
- Software can be added as a standalone option in an Add-on deal (no hardware required)

### Software Pricing Table
Pricing is shown in the Software Pricing Table within [[10_Pricing]]:
- **Total Upfront Cost** = licence price (MPC pre-approved price) × quantity
- **Total Monthly Cost** = monthly service & support charge × quantity
- **Customer Upfront Price** = Total Upfront HP cost ÷ (1 − target margin%)
- **Total Customer Monthly Price** = Total Monthly HP cost ÷ (1 − target margin%)
