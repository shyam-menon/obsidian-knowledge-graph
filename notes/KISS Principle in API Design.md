**Title:** KISS Principle in API Design

**Idea:** "Keep It Simple" applied to APIs means designing around client use cases rather than internal systems, using common non-technical language, and ensuring there is only one obvious way to accomplish any given task. Simplicity reduces the cognitive overhead for integrating developers.

**Why it matters:** APIs with multiple overlapping ways to do the same thing lead to inconsistent integrations, bugs, and higher support costs.
