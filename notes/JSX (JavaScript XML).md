**Title: JSX (JavaScript XML)** 

**Idea:** A syntax extension for JavaScript that allows you to write HTML-like structures directly inside your JS/TS logic. 

**Why it matters:** Allows developers to see the visual structure of a component alongside the logic that controls it. 

**Trade-offs:** Requires a build tool (like Vite) to transform it into standard JavaScript that browsers can understand.
