**Title: Native ESM Serving (Vite)

**Idea:** Vite serves source code using the browser's built-in `import` system, bypassing the need to bundle thousands of files into one large file during development. 

**Why it matters:** It makes "Cold Starts" irrelevant. The time to start a dev server is independent of the size of the project.
