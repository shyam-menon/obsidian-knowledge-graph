**Title: Vite Hot Module Replacement (HMR)

**Idea:** A protocol that allows Vite to "push" specific file changes to the browser without a full page reload. **Why it matters:** Preserves application state (like data in a form) while you are actively editing the UI, resulting in a seamless "Flow State" for the developer.
