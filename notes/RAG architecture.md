Title: RAG Architecture

RAG (Retrieval-Augmented Generation) combines retrieval systems with LLMs to generate grounded responses.

Core components:
- Retrieval (vector search / hybrid search)
- Context assembly
- Generation (LLM)
- Evaluation loop
