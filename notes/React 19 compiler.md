**Title: The React 19 Compiler

**Idea:** A build-time tool that analyzes React code and automatically injects memoization logic to prevent unnecessary re-renders. 

**Why it matters:** It marks the end of "Manual Optimization" (no more `useMemo` or `useCallback`), allowing developers to write standard JS that performs at peak efficiency.
