**Title:** REST URL Design Conventions

**Idea:** Well-designed REST URLs follow four rules: use nouns (not verbs) for resources, use plural nouns to handle both collections and individual items consistently, use hierarchical path segments to express relationships, and maintain a single consistent casing convention (camelCase, snake_case, or spinal-case) throughout.

**Why it matters:** Consistent URL design allows developers to intuitively guess endpoints, reduces documentation dependency, and prevents API sprawl.
