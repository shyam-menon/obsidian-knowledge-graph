**Title: Declarative UI (React)** 

**Idea:** Instead of telling the browser step-by-step how to change (Imperative), you tell React the final state you want, and it handles the transition. 

**Why it matters:** Reduces bugs related to manual DOM manipulation and makes code much easier to reason about as it scales.
