**Title:** Task Decomposition for Agent Systems

**Idea:**  
Task decomposition is the process of breaking complex problems into smaller, structured steps that can be handled by individual agents or components. Each step should have a clear purpose and input/output.

**Why it matters:**  
Well-decomposed tasks improve system reliability, scalability, and clarity in AI systems.
