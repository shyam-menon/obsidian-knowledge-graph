**Title:** AI Failure Pattern Recognition

**Idea:**  
Failure pattern recognition is the ability to identify recurring AI system issues such as hallucination, context loss, tool misuse and silent errors, and trace them to root causes.

**Why it matters:**  
Recognizing patterns enables faster debugging and more robust system design.
