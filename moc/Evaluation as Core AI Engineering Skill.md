**Title:** Evaluation as Core AI Engineering Skill

**Idea:**  
AI systems must be evaluated using structured tests because outputs can appear correct while being wrong. Evaluation involves systematically testing AI outputs against defined criteria to determine correctness, completeness, and reliability.

**Why it matters:**  
AI outputs can appear correct while being wrong. Evaluation ensures trust and enables continuous improvement of systems.
